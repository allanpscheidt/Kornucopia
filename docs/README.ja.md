# Kornucopia

Kornucopiaは、Apple Silicon搭載MacとWindows 11向けの、付箋を使ったローカルKanbanアプリです。未着手、作業中、確認、完了の各列に実践的なチュートリアルがあり、列ごとに異なる色を使います。

**[最新版をダウンロード](https://github.com/allanpscheidt/Kornucopia/releases/latest)** · [Português brasileiro](../README.md)

## バージョン1.0.1

- 4つの列それぞれに実践的なチュートリアル。
- ブラジルポルトガル語、英語、スペイン語、フランス語、日本語の画面表示。
- 設定で選んだ言語を保存。入力したカードの文章はそのまま保持。
- Mac arm64版とWindows x64・ARM64のポータブル版。

作業中の初期上限は2枚です。上限に達すると、追加のカードを入れる操作を警告画面でブロックします。新しい作業を始める前に、進めている作業を終えて確認へ移動してください。上限は設定で増やせます。他の列にはカード枚数の人為的な制限がありません。

## インストールと使い方

「閉じる」などmacOS標準のコマンドはシステムの言語に従います。設定で選んだ言語は、Kornucopiaの操作表示、警告、チュートリアルに適用します。

Mac版はApple SiliconとmacOS 14以降に対応します。macOS arm64のZIPを展開し、Kornucopia.appをアプリケーションフォルダにコピーしてください。配布版はアドホック署名を使用し、Developer ID署名やAppleの公証はありません。初回起動がブロックされた場合は、[Appleの案内](https://support.apple.com/ja-jp/102445)を確認してください。

Windows 11では、プロセッサに合わせてx64またはARM64のZIPを選びます。フォルダ全体を展開し、Kornucopia.exeとResourcesを同じ場所に置いて起動してください。必要なランタイムを含みます。現在の配布版にはAuthenticode署名がありません。入手元を確認し、システムの保護機能を有効にしてください。

未着手にアイデアを追加し、タイトルとメモを編集して、各列の説明に沿って作業を進めます。ドラッグまたは編集画面でカードを移動できます。設定で言語と作業上限を変更できます。列の色は黄色、青、紫、緑です。

変更は自動保存します。保存先はMacでは `~/Library/Application Support/Kornucopia/`、Windowsでは `%LOCALAPPDATA%\Kornucopia\` です。JSONファイルは読み取れるテキストで、直前の状態のバックアップも保持します。このフォルダを通常のバックアップに含めてください。アカウントやクラウド同期を使わず、ローカルで動作します。
